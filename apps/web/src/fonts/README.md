# Fonts

`Excalifont-Latin.woff2` is the Latin subset of Excalifont, copied from the `@excalidraw/excalidraw` 0.18.1 package.
Excalidraw publishes Excalifont under the SIL Open Font License 1.1 (https://plus.excalidraw.com/excalifont).
It is bundled here so the app loads no font from another site (the served page blocks other origins).
